# 时间线 UI 手动验证清单（阶段②）

模拟器手动验证（标注「真机」的项需真机）。每项步骤执行一次后勾选「结果」。

前置：App 内先往沙盒播种样例内容（命令见 AGENTS.md「常用命令」），进剪辑页，确认时间线有至少两条元素（主轨）+ 一条可叠加的素材。

## 手势

- [ ] **单指左右拖 = 滚动 = 擦洗**
  - 步骤：单指在非选中元素的轨道内容上左右拖；再快速甩一下松手。
  - 期望：内容平移、播放头恒居中、预览跟随 seek；松手不弹回（停在拖到的位置）；**滚动跟手不掉帧**（擦洗 seek 带 0.1s 容差，停稳才精确对齐）；**甩动后带惯性继续滑**、预览跟着滚。
- [ ] **播放自动滚动**
  - 步骤：起播，观察时间线。
  - 期望：自动滚动**连续平滑**（非 10Hz 跳步）；播放头时间标签与预览画面同步。
- [ ] **单指上下拖 = 纵向滚轨道列表（仅轨道装不下时）**
  - 步骤：轨道装得下时单指上下拖；再把时间线拉到装不下，重复。
  - 期望：**装得下时纵向拖不动列表、也不擦洗**（纵向手势无副作用）；装不下时纵向滚动列表、播放头不动；**与横向滚动互不串轴**。
- [ ] **轴锁定**
  - 步骤：起手横向拖到一半再往上拐；再反过来（起手纵向、中途往右拐）。
  - 期望：**起手定的轴全程不变**——先横后竖仍只横向滚动（列表不跟着上下跑）；先竖后横只纵向滚动（不擦洗）。
- [ ] **双指捏合缩放**
  - 步骤：双指在时间线上捏合 / 张开。
  - 期望：锚点 = 双指中心（缩放前后该点下的内容不漂移）；缩放期间不擦洗；档位角标出现、停止操作 1s 后淡出。

## 选中与 trim

- [ ] **点元素选中**
  - 步骤：点主轨某元素，再点空白区。
  - 期望：选中出 trim 手柄 + 边框；点空白取消选择。
- [ ] **拖 trim 手柄**
  - 步骤：拖选中元素左右边缘手柄。
  - 期望：元素与选中框同步伸缩、预览跟随；松手后撤销栈只 +1（按一次撤销还原）。
- [ ] 擦洗让位只挡手柄区
  - 步骤：选中一元素后，在其**体上**横向拖，再在**手柄上**横向拖。
  - 期望：体上拖 = 擦洗（内容平移）；手柄上拖 = trim（不擦洗）。

## 拖动与重排

- [ ] **长按元素 → 浮起 → 拖（移动 / 换轨）**
  - 步骤：长按某元素浮起后拖动，横向移动位置、纵向拖到另一条轨。
  - 期望：元素跟手移动 / 换轨；**拖动期间预览不重建、plan 不变**；松手落一次编辑（撤销栈 +1）。
- [ ] **长按轨道头 → 上下拖（轨道重排）**
  - 步骤：长按轨道头的图标 / 编号区域浮起后上下拖。
  - 期望：轨道层序变化，预览层序随之更新。
- [ ] **拖分界横杠 + 三档吸附**
  - 步骤：拖预览 / 时间线之间的横杠，松手。
  - 期望：吸附到三档（预览最小高 / 时间线半屏 / 时间线近全屏）。

## 呈现

- [ ] **缩略图呈帧格胶片条、滚动不重取**
  - 步骤：看某片段（多格帧格、格宽按素材宽高比；**图片元素也应铺成同样的帧格，不出现只露一条横带**）；再快速横向滚动，观察缩略图。
  - 期望：片段是**多格胶片条**，不出现「整段只剩一帧、且随播放头变换」；横向滚动时格随滚动平移、已抽好的帧不重取；**滚动过程中不出现「空白 → 缩略图」的跳变**（未抽好的格用最近帧顶替）；**来回滚动回到刚看过的区域时不整条闪空白**；缩放时格宽在屏幕上不变，只改变「每格代表多少秒」。
- [ ] **轨道头钉左缘、无实色底、纵向跟轨**
  - 步骤：横向滚动 + 纵向滚动。
  - 期望：轨道头横向恒钉视口左缘、纵向跟着自己那条轨走、滚出屏幕一起被裁；无实色底，文字在任何素材上都可读。
- [ ] **静音 / 隐藏按钮**
  - 步骤：点叠加轨的隐藏按钮；再点主轨的隐藏按钮。
  - 期望：隐藏轨在预览里消失；主轨隐藏按钮禁用。

## 布局预设

- [ ] **左右分屏**
  - 步骤：选中主轨元素 → 布局 → 左半屏；选中叠加轨元素 → 布局 → 右半屏。
  - 期望：**预览里**看到左右两块（若预览不显示 transform，登记降级项）。

## 选中态操作条

- [ ] **变速 / 转场 / 删除**
  - 步骤：选中元素，分别用变速、转场、删除。
  - 期望：变速 / 转场即时反映在预览；删除后**原地留 gap、成片时长不变**。

## 真机回归

- [ ] **叠加轨在预览中可见（回归）**
  - 步骤：真机上让叠加轨区间进入预览播放。
  - 期望：叠加区间内叠加轨内容出现、结束后回到主轨（末帧未被保持）。
